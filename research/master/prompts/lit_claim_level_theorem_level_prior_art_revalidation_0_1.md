## Package-level audit

After claim-by-claim analysis, assess whether the package

`synergetic slaving bridge -> exact application witnesses -> active same-macro hidden-state preparation`

supports a defensible **restricted synthesis contribution** even if individual ingredients are prior art.

A package/conjunction alone is not novelty. A positive recommendation requires a precise reason the integration, theorem relation, diagnostic consequence, or prospective evidence structure is not merely a relabeling of existing frameworks.

## Search discipline

- Search current literature through the execution date.
- Prioritise primary sources, canonical monographs/papers, journal/conference proceedings and authoritative reviews.
- Search exact mathematical analogues, not project terminology alone.
- For every potentially positive distinction, actively search for the strongest SAME/CLOSE counterexample.
- Absence of a SAME hit is never novelty proof.
- Distinguish publication date from event/result date where relevant.
- Record search terms/families sufficiently for auditability.

## Decision semantics

### MANUSCRIPT-READY — CLAIM-RESTRICTED

Use only if the audit identifies a defensible manuscript contribution under explicit restricted wording and mandatory prior-art positioning. This does not assert field-level novelty.

### REVISE CLAIM SET

Use if the evidence can support a paper only after dropping or materially narrowing exactly specified claims. Do not invent replacement science.

### STOP — NO DEFENSIBLE CLAIM PACKAGE

Use if the final package is fully subsumed/redundant such that manuscript investment under the current framing is not justified.
