## Central research question

Which macroscopic description of a complex system is sufficient not only for its spontaneous dynamics, but also for predicting and controlling a defined class of interventions?

The programme treats causal synergetics as a proposed research field to be tested, not as an already established theory.

## Initial programme logic

The long-term target is to test whether low-dimensional intervention-sufficient state descriptions can be connected nontrivially to synergetic order-parameter dynamics, slaving, local atlases, and controlled state preparation.

The programme must remain falsifiable. In particular, it must allow outcomes in which:

- standard or passive macrostates are already sufficient;
- no low-dimensional intervention-sufficient representation exists;
- existing theories fully subsume the proposed claims;
- the synergetic structure is not needed;
- only domain-specific rather than field-level claims survive.
