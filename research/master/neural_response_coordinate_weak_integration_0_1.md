The neural response-coordinate direction is **not stopped**, because the frozen candidate coordinate achieved essentially exact held-out intervention prediction with all sanity, leakage, oracle, and regression checks passing. However, the direction is **not advanced directly to broader neural claims**, because the equal-dimensional raw-parameter PCA baseline was also essentially exact and the frozen material-advantage discriminator therefore failed.

The programme action is **REVISE**.

That gate must define exactly one falsifiable benchmark testing whether a response-aware coordinate retains predictive sufficiency under pre-declared response-irrelevant/raw-parameter nuisance variation while equally compact raw-state representations are evaluated fairly under the same fixed protocol.

This decision does not authorise execution of such a benchmark yet.

## 3. What the WEAK result establishes

The frozen result establishes only the following restricted statement:

> In the specified 81-state factorised-linear synthetic family, a two-dimensional response-aware coordinate constructed from four calibration interventions predicts eight held-out one-step interventions essentially exactly on held-out states.

It also establishes that current-function features and the pre-declared simple summary baseline do not recover the relevant state-conditioned response geometry.

## 4. What it does not establish

The result does not establish:

- material predictive value of response-aware coordinates beyond equally compact raw-state geometry;
- a generally useful causal/plasticity coordinate;
- robustness to parameterisation nuisance or gauge freedom;
- generic nonlinear or multi-step behaviour;
- realistic SGD-history relevance;
- real-data, LoRA, adapter, or transformer usefulness;
- controlled state preparation;
- novelty or an established field of causal synergetics.

## 5. Diagnosis of the near-tie with B2

### Directly shown

The direct frozen fact is that 2D raw-parameter PCA nearly matches the 2D response coordinate on the same held-out prediction task.

### Plausible inference, not yet established

A plausible explanation is that the frozen state family has an intrinsically low-dimensional raw-parameter geometry that is already aligned closely enough with the response-relevant geometry for 2D raw PCA to recover almost all predictive information.

This explanation is **not** itself a frozen result. The current gate does not infer that response-aware coordinates are unnecessary in general, nor that raw-state PCA will remain sufficient under reparameterisation nuisance.

No execution is authorised until this specification itself is frozen.

## 8. Reasons for rejecting the main alternatives

### Direct GO to nonlinear/multi-step scaling — rejected

The present unresolved issue is discriminative value versus raw-state geometry. Scaling the same unresolved claim to nonlinear or multi-step settings would add complexity before resolving the central comparator failure.

### Realistic-history work — rejected for now

History realism remains important, but it does not address why the response coordinate failed to outperform an equally compact raw-state representation.

### Immediate second coordinate or alternate family — rejected

That would violate the spirit of the anti-retuning freeze because the current family has already produced a WEAK result. Any new family must arise from an independently motivated control question, not effect-guided search.

### STOP — rejected

Stopping is premature because the candidate did achieve exact held-out prediction and passed every validity control. The WEAK result isolates a specific, falsifiable unresolved issue rather than showing collapse of the coordinate idea.
