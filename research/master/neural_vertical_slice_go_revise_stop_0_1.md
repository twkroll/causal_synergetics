## 3. Strongest positive evidence

1. **No rescue-by-retuning was required.** Each executed empirical gate used a specification frozen before result inspection and passed without alternative candidates, learning rates, tasks, horizons, probes, tolerances, or optimizers.
2. **Function equality is exact, not approximate, in the two central neural demonstrations.** The linear pair has identical effective function `w=0`; the ReLU pair is globally function-equivalent by positive homogeneity.
3. **The intervention response is directed rather than merely different.** In both linear and ReLU pilots the symmetric task pair reverses which state adapts more strongly.
4. **The nonlinear pilot survives a representation symmetry.** The ReLU result shows that the phenomenon is not confined to the exact factorised-linear algebra used in the first benchmark.
5. **The mathematical and empirical stories are compatible.** CORE says passive/equilibrium or function-level sufficiency need not imply controlled/intervention sufficiency; the neural pilots provide concrete learning-dynamics witnesses of that general distinction without claiming the witnesses instantiate a novel theorem.
6. **The project remains falsifiable.** The next stage can be defined so that failure to predict held-out interventions beyond simple baselines materially weakens the neural programme rather than being repairable by another showcase example.

---

## 4. Strongest negative evidence / limitations

1. **Novelty remains highly constrained.** The literature audit demoted the generic conceptual core; no field-level novelty claim is currently defensible.
2. **CORE novelty remains unresolved.** The exact closure criterion is prior-art structure, and the finite-horizon bridge uses standard stability machinery. A theorem-to-theorem novelty comparison has not been completed.
3. **Historical reachability is artificial.** The only proved preparation history uses a temporary orthogonal auxiliary head and one purpose-built gradient step. It does not show that ordinary training naturally produces the relevant states.
4. **The nonlinear evidence is still a symmetry construction.** Positive-homogeneous ReLU rescaling gives exact function equivalence by design. This is a clean control, but it is not yet evidence of generic behaviour across realistic networks.
5. **All neural evidence is one-step and tiny-scale.** No multi-step, stochastic, real-data, deep-network, adapter, LoRA or transformer result exists.
6. **No response/plasticity coordinate has yet been learned or validated.** The programme has demonstrated state insufficiency, not yet successful state reduction.
7. **No held-out intervention generalisation has been shown.** This is presently the most important missing empirical capability.

## 6. Single next recommended scientific gate

### `Neural Response Coordinate Specification Gate 0.1`

This should be a **MASTER specification/freeze gate**, not an execution gate.

Its purpose is to define one falsifiable predictive benchmark in which a compact response/plasticity representation is trained or constructed using a frozen training intervention set and evaluated on held-out interventions, with pre-declared baselines and success criteria.

The specification gate must freeze before any execution at least:

- neural model/state family and how function-equivalent or near-equivalent states are generated;
- intervention family and train/held-out split;
- response functional and horizon;
- candidate coordinate dimensionality and learning/construction rule;
- information available to the coordinate learner;
- mandatory baselines, including current-function features and simple norm/state summaries, plus any stronger baseline justified before execution;
- prediction metric and aggregation rule;
- null/control conditions;
- success, weak, null and fail thresholds;
- random seeds/splits if stochastic components are admitted;
- explicit prohibition on representation/hyperparameter search after held-out inspection.

The key falsification question is:

> Does a compact, pre-specified response/plasticity representation predict held-out learning interventions materially better than the frozen non-response-aware baselines?

A failure here would materially weaken the neural vertical slice because the programme would remain a collection of intervention-insufficiency examples without evidence for useful low-dimensional predictive state reduction.

This gate is recommended only for specification. No learned-coordinate execution is authorised by the present GO decision.

## 7. Why the main alternatives are not selected now

### Not `REVISE` via theorem-to-theorem prior-art audit

Publication-level novelty of the CORE bridge is unresolved, but that does not block testing whether the neural programme has empirical predictive value. The value of the theorem novelty audit is higher after establishing that the empirical reduction problem is nontrivial and useful. If held-out predictive coordinates fail, a deeper novelty audit becomes less urgent.

### Not `REVISE` via realistic nonlinear-history reachability

The artificial auxiliary history is a real limitation, but realistic reachability is not the central next uncertainty. It would make the example more natural without testing whether the proposed response-state programme can actually compress and predict intervention futures.

### Not another nonlinear showcase

A further hand-built architecture or symmetry example would have low information value and increase the risk of example accumulation. The next gate must test prediction/generalisation, not existence of another crossing.

### Not multi-step / real data yet

Scaling before a frozen predictive representation and baseline test would multiply degrees of freedom and invite post-hoc choices. First determine whether the response-coordinate idea works in a tightly controlled setting.

### Not LoRA / adapters / transformers

These are higher-cost application variants of a capability not yet demonstrated. They remain blocked.

### Not power grid

Cross-domain validation is strategically important, but opening a second domain before demonstrating the core empirical reduction step in the neural vertical slice would create premature branch proliferation.

### Not controlled state preparation

State preparation presupposes a meaningful response-state target. Prediction should precede control.

### Not `STOP`

STOP is not justified because every pre-specified stage in the vertical slice has passed without retuning and there is a clear, falsifiable next question with high information value.
