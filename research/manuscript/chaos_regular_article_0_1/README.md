# Chaos Regular Article Package 0.1

This directory is the claim-neutral venue adaptation authorised under `Manuscript Chaos Regular-Article Format Adaptation 0.1`.

Primary venue: **Chaos: An Interdisciplinary Journal of Nonlinear Science** (AIP Publishing).

Article type: **Regular Article / Research Article — NOT Fast Track**.

## Package contents

- `manuscript_chaos_0_1.tex` — AIP/Chaos-oriented REVTeX source.
- `supplement_chaos_0_1.tex` — supplementary-material LaTeX wrapper carrying the complete frozen Appendices A–F from `../venue_neutral_0_2/supplement_0_1.md` through the TeX `markdown` package, without scientific rewriting.
- `references_chaos_0_1.bib` — the existing frozen cited-work set normalized for author-year BibTeX use; no work added or removed.
- `alt_text_0_1.md` — neutral accessibility descriptions for Figures 1–4.
- `submission_metadata_checklist_0_1.md` — venue metadata/declaration checklist with `AUTHOR INPUT REQUIRED` placeholders.
- `CHANGELOG.md` — exact claim-neutral adaptation record.

The scientific SVG figures are not duplicated. The manuscript source references the byte-frozen files under `research/manuscript/venue_neutral_0_2/figures/`.

## Source-of-truth boundaries

The following remain unchanged and controlling:

- `research/manuscript/manuscript_editorial_completion_0_1.md`;
- `research/manuscript/venue_neutral_0_2/`;
- `research/master/manuscript_claim_freeze_architecture_0_1.md`;

The Chaos adaptation shortens only the abstract to the frozen AIP limit, creates the required Lead Paragraph from already frozen introductory material, converts the content to venue-oriented LaTeX structure, adds declaration placeholders/alt text, and normalizes reference presentation. Mandatory WEAK/FAIL/Gram/PARK/mean-COI evidence remains visible in the main body.
